# Механикадағы күштер — 9-сынып

Интерактивті слайд-зертхана (физика, 9-сынып, оқу мақсаты 9.2.2.3). Соңында әр оқушы телефонмен қатысатын көлік жарысы бар.
Мұғалім: Төленді И.Н., «Тайтөбе ауылының жалпы орта білім беретін мектебі» КММ.

## Ашу
- Интернет арқылы: барлық файлды GitHub Pages-ке жүктеп, сілтемені ашу.
- Wi-Fi бар сыныпта: `start.bat` (телефондар компьютермен бір желіде болсын).
- `index.html`-ді екі рет басып ашсаңыз, слайд жұмыс істейді, бірақ QR шықпайды.

## Басқару
- ← → немесе PageUp / PageDown — беттер (жарыс кезінде: жауап → келесі сұрақ)
- F немесе жоғарғы батырма — толық экран, T — тақтаны жасыру/шығару
